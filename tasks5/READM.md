▶️ Running the Application

Install dependencies:

pip install -e .


Run the task manager using:

python -m taskmgr add "Wash dishes"
python -m taskmgr list
python -m taskmgr done 1


All tasks are stored in a JSON file managed by the storage.py module.

🧪 Running Tests
